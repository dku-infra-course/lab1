# week01 (1주차) · Solid Cloud 환경 준비와 첫 가상 머신

실습 가이드: `실습_W1_환경준비.html`

1주차는 대부분 **웹 콘솔 조작** 이라 실행할 코드가 없다. 이 폴더는 콘솔에서 무엇을 만들었는지 확인하는 **체크리스트와 검증 명령** 만 담는다.

## 1. 목표

- Solid Cloud 대시보드에 접속하고 실습용 **격리 네트워크(Isolated Network)** 를 만든다.
- 가상 머신(VM)을 배포하고 **Egress · 방화벽 · 포트포워딩** 을 설정하여 외부에서 SSH로 접속한다.
- 이론 1주차의 "인프라의 기반 계층"을 실제 클라우드 콘솔에서 확인한다.

## 2. 사전 조건

- 학교 계정 발급과 VPN 접속 절차: 「02. 사용자 설명서」·「06. SOLID Cloud 접속 가이드」참조.
- Solid Cloud 콘솔 URL: `https://dku.kloud.zone`
- 로컬 터미널. Windows는 PowerShell 또는 MobaXterm.
- Solid Cloud는 교내망/VPN에서만 접근된다. 실습 내내 VPN 연결을 유지한다.

## 3. 실행 순서 (콘솔 조작 체크리스트)

순서대로 체크하며 진행한다.

- [ ] **1) 대시보드 로그인** · VPN 연결 후 로그인, 좌측 메뉴에서 `[네트워크]` 와 `[컴퓨트]` 위치 확인
- [ ] **2) 격리 네트워크 생성** · `[네트워크]` → `[네트워크 추가]` → **Isolated** 선택
      - 이름: `net-{{STUDENT_ID}}`
      - 네트워크 오퍼링: 기본 제공 오퍼링 (잘못 고르면 이후 포트포워딩·방화벽 항목이 보이지 않는다)
      - CIDR: `192.168.0.0/24` (3주차 이후 설정을 그대로 쓰려면 이 대역을 권장)
- [ ] **3) VM 배포** · `[컴퓨트]` → `[인스턴스]` → `[인스턴스 추가]`
      - 템플릿: Ubuntu LTS (제공 목록에서 선택)
      - 컴퓨트 오퍼링: `Small`(1core/2GB)로 충분하다. Web IDE를 쓸 계획이면 `Medium`(2core/4GB) 이상
      - 네트워크: 2)에서 만든 격리 네트워크
      - SSH 키쌍: 있으면 등록, 없으면 콘솔 접속용 비밀번호 확인
      - 배포 후 상태가 `Running` 이고 사설 IP가 할당되었는지 확인
- [ ] **4) Egress 규칙** · `[네트워크]` → 해당 네트워크 → `[Egress 규칙]` 에서 아웃바운드 허용
      - 격리 네트워크는 기본적으로 나가는 트래픽이 차단되어 있어, 이 상태로는 패키지 설치가 안 된다.
      - 실습 편의를 위한 임시 설정이다. 운영에서는 필요한 목적지·포트만 최소로 허용한다.
- [ ] **5) 포트포워딩** · 가상 라우터 공용 IP의 `2201` → VM의 `22` (SSH)
- [ ] **6) 방화벽** · `2201` 개방, **Source CIDR를 VPN 대역으로 한정**
      - `0.0.0.0/0` 으로 열지 않는다. VPN 대역은 `10.8.0.0/24`(넷마스크 `255.255.255.0`)다.
- [ ] **7) SSH 접속 확인**

## 4. 검증 방법

로컬 터미널에서:

```bash
ssh -p 2201 ubuntu@{{PUBLIC_IP}}
```

접속된 VM 안에서:

```bash
# 어느 서버에 어느 계정으로 접속했는지
whoami
hostname

# 사설 IP가 할당되었는지
ip a

# Egress(아웃바운드)가 열렸는지
sudo apt update
```

통과 기준

- VM이 `Running` 이고 사설 IP가 할당되었다.
- 가상 라우터 공용 IP + 포워딩 포트로 SSH 접속에 성공한다.
- `sudo apt update` 가 오류 없이 끝난다(Egress 허용 확인).

## 5. 정리 (rollback)

Solid Cloud는 캠퍼스 전체가 나눠 쓰는 자원이다. 이번 주 확인이 끝났으면 아래 역순으로 정리(Destroy)한다.
다음 주차는 이 환경을 이어 쓰지 않고 새로 만든다.

1. 방화벽 규칙 삭제 (`2201`)
2. 포트포워딩 규칙 삭제
3. VM 정지 후 삭제 (`Expunge` 까지 해야 완전히 정리된다)
4. 격리 네트워크 삭제
